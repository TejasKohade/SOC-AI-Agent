# Rule tuning from CASE-A8167A84

Case: Phishing email with look-alike domain or user report on mail-gw  
Verdict: malicious

- **autosoc-phishing-url**: Enhance the rule to include look-alike/homoglyph domain detection (e.g., character substitution patterns such as '0' for 'o') at the mail gateway level to catch these emails before delivery, rather than relying solely on post-delivery URL reputation checks. Additionally, consider adding a detection layer for emails where the sender domain does not match the impersonated organisation's known domains.
